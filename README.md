# 格物 · 大模型知识库

## 功能

- **目录**：板块/分组结构与源库一致，文档按真实层级重排、序号连续；侧栏可拖拽调宽，悬停显示完整标题
- **全文搜索**：`Ctrl/⌘ + K` 唤起，标题与正文命中、摘要高亮、键盘选择
- **书签续读**：右下角书签丝带，随时一键回到标记处并恢复阅读位置
- **收藏**：一键收藏文档，侧栏「我的收藏」分组管理
- **标注笔记**：选中文字或图片即可批注（正文高亮 + 页边卡片 + 牵引线），完整增删改
- **账号体系**：邮箱注册/登录，收藏、标注、书签按账号云端隔离存储；登录前数据自动并入账号
- **管理后台**：站点管理员可查看注册用户（邮箱/注册 IP/注册地）与数据统计，支持清空数据、重置密码、删除用户
- **PDF 阅读**：文本型 PDF 自动还原为网页排版；设计型 PDF 整页原图内嵌
- **阅读辅助**：大纲滚动联动、阅读进度条、上/下篇导航、图片灯箱、代码一键复制、明暗主题记忆

## 快速开始

要求：Python 3.9+，无需数据库（SQLite 内嵌）。

```bash
python3 app.py          # 打开 http://127.0.0.1:8686
python3 app.py 9000     # 或指定端口
```

使用要点：

- 访客可直接阅读全部内容（数据保存在本机浏览器）
- 点右上角「登录 / 注册」创建账号后，收藏 / 标注 / 书签保存到云端，换设备登录同一账号即可同步

## 生产部署

```bash
pip install flask gunicorn
gunicorn -w 2 -b 127.0.0.1:8686 app:app
```

建议前置 nginx / Caddy 提供 HTTPS 与静态资源加速。资源参考：磁盘约 5 GB（PDF 页图 + 附件 + 正文图片），内存 128 MB 起，1 核 CPU 足够个人使用。

## 重新构建数据（可选）

`data/` 已包含全部构建产物，开箱即用。需要从原始快照重新生成时：

```bash
python3 tools/build_data.py        # 读取 _raw/，产出 data/ 全部索引与分块
python3 tools/verify_content.py    # 全量校验 PDF 网页化还原度
```

## 目录结构

```text
.
├── app.py                 # 服务器：静态站点 + 账号体系 + 管理接口
├── index.html             # 页面入口（单页应用）
├── assets/                # 前端脚本 / 设计系统 / 站点图标 / PDF 页图与正文图片
├── data/                  # 构建产物：目录、分块正文、全文搜索索引
├── attachments/           # 附件本地化副本
├── tools/                 # 构建与校验脚本
└── _raw/                  # 原始快照（docs/toc/imgmap）与运行数据库
```

## 技术栈

- 后端：Python Flask + SQLite（密码 PBKDF2 哈希，无外部服务依赖）
- 前端：原生 JavaScript 单页应用 + 语义化 CSS 变量设计系统（无框架、无构建步骤）
- 内容管线：语雀 Lake 文档转换、pdfminer 版面还原、PyMuPDF 页面渲染
